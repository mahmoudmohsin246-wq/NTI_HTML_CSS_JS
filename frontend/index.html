🖥️ Backend Integration Architecture

This frontend application connects dynamically to your original Python backend logic (student_function.py, course_function.py, search_GPA.py, save_load.py) exposed via a clean Flask REST API wrapper (app.py).

  • Student Management: Student class instantiation, property updating, deletion, and course sign-up.
  • Course Ledger: Course object management, grade ledger mapping, and credit hour calculations.
  • GPA & Average Computation: Updated weighted scale GPA converter and class averages.
  • JSON & CSV Persistence: Automatic saving and loading to student.json and course.json, and export to report.csv.
